## 1. 编号结构

一个被评价的策略完整写作：

```
P<运行编号>@u<外层更新轮数> #E<评价协议编号>
```

| 部分 | 含义 | 例子 |
|---|---|---|
| **方法族 F** | 训练配方：从哪里开始、用什么目标函数和额外损失项。不含随机种子 | F3 = 第二阶段续训 + 固定成功行为保持 |
| **运行编号 P** | 一次具体的训练运行：方法族 + 父模型 + 随机种子 + 全部超参数。同一方法换 seed 重跑，就是新的 P 编号 | P5 = F2 的第三次运行 |
| **检查点 @u** | 该运行第几次外层更新后的权重 | @u128、@u256 |
| **评价协议 #E** | 评价时的采样设置 | #E1 = 原协议（去噪截断 1.0） |

省略规则：
- 省略 @u 时，指该运行的终点检查点（第 7 节表中的"终点"列）。
- 省略 #E 时，指 #E2（2026-10-31 起的统一协议）。#E1 只用于历史结果。

## 2. 编号规则

1. **编号只增不改，不复用。** 新运行从 P8 开始顺序编号。即使运行失败或被废弃，编号也保留，在第 7 节注明状态。
2. **一次运行一个编号。** 只要父模型、seed、配置文件（哈希）、代码版本中任一项不同，就是新编号。同一运行的不同检查点用 @u 区分，不另起编号。
3. **新方法族从 F5 开始编号。** 只有训练配方变化（新的损失项、新的采样方式、新的奖励、新的任务分布）才新开方法族。只改 seed 不开新方法族。
4. **登记先于运行。** 新运行启动前，先在本文第 6、7 节登记方法族、父模型、seed、相对共用设置的全部差异和配置文件路径。结果回传后再补检查点身份和评价结果。
5. **配置以文件为准。** 本文表格是摘要。若与配置文件冲突，以配置文件和其 sha256 为准，并在本文修正。
6. **评价协议单独编号。** 采样设置（去噪截断、噪声下限等）只在评价时改变，属于新的 #E 编号，不算新运行。训练时采样设置变了，才算训练配方的一部分。

## 4. 方法族

| 编号 | 名称 | 定义 |
|---|---|---|
| F0 | BC 基线 | 不做 RL，直接使用 E5 BC 策略 |
| F1 | 第一阶段 PPO | 从 F0 开始，按共用设置训练 |
| F2 | 第二阶段直接续训 | 从第一阶段的 @u128 继续训练到 @u256，不加任何额外损失项 |
| F3 | 第二阶段续训 + 固定成功行为保持 | 同 F2，另加固定参考库的保持损失（定义见 6.6） |
| F4 | 第二阶段续训 + 改进组合 | 同 F2，另加三项改动：惰性通道掩码、自模仿保持、训练采样截断 2.0（定义见 6.8） |
| F5 | 第二阶段续训 + 固定成功行为保持 + 难度任务库 + reward v3 | 同 F3，另加两项：按难度分层的训练任务库混合采样（受阻任务约占 60%），以及 reward v3 的接近速度风险项（定义见 6.9） |

### 6.6 P6：第二阶段续训 + 固定成功行为保持（F3）
（P5 定义在 6.7。按时间顺序 P6 早于 P5，编号沿用已确认的列表。）
- 父模型：P2@u128；随机状态和优化器状态的恢复方式同 P4。
- 额外损失：总损失 = PPO 损失 + λ × 保持损失。
  - **参考库：** 固定，不随训练更新。内容是 P0 和 P2@u128 在训练任务上成功回合的实际执行前缀，按"两者都成功 / 只有 BC 成功 / 只有 RL 成功"三类分层，按任务均匀抽样。参考库文件 sha256 `8759fc40…`
  - **损失形式：** 在 DDIM 微调去噪步上做 x0 去噪监督，只监督实际执行部分的位置和偏航通道（0、1、2、9），按执行比例加权。实现见 `engine/selective_keep.py`。
  - **系数：** λ=0.01061，训练开始时一次性标定，之后不调整，标定目标是保持梯度范数约为 PPO 梯度范数的 0.1 倍。训练中实测比例的中位数是 0.047。保持项抽样 seed 2026102301。
- 运行身份 `d987235a0cbb`；输出 `.../routea_a2_selective_keep_run01/T/`
- 配置：`jindu/routea_a2_selective_keep_run01/arms/T.yaml`（main 分支），sha256 `4dddd1fc…`。保持系数见 `arms/T/keep_calibration.json`：0.01061006，目标比例 0.1。
- 参考库：`reference/inventory.json`，126 个候选任务，其中 47 个可用（两者都成功 22 个、只有 RL 成功 23 个、只有 BC 成功 2 个），共 549 个样本。按路线带口径，带内无障碍 183 个样本、带内低 238 个、带内高 128 个。2026-10-31 已核实。
