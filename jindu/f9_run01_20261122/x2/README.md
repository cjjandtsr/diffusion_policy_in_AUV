# F9 诊断 X2：离线监督拟合（P37/P38）

日期：2026-11-24/25。依据《F9 离线拟合探针 X2 WSL 执行指引 v1_0》。
**只做离线监督拟合**：不仿真、不进 PPO、权重不部署、无闭环评价。

## 设置

- 训练集 T：P28/P35/P36 u264 缓冲区快照的 `records`，按 observation_sha256 去重、剔除与 U 相交者
  → **|T| = 863**（P28 212、P35 376、P36 275；剔除 U 相交 **0** 条）
- 目标：每条 T 用 P6（训练前）确定性成对链生成 `y = normalize(full)`（种子 2026112600 + j），固定不变
- 两臂均从 P6@u256 重新加载：P37 lr 1e-5 / P38 lr 1e-4，batch 256，2000 步，AdamW(wd .01, betas .9/.999, eps 1e-8)，
  梯度裁剪 5.0；每步随机种子固定 2026112601（两臂序列相同）
- 测量点 0/250/…/2000；U = X1 的 83 状态（b_P6、g_P6 直接取 X1 原始量）
