## 0. 结论摘要

1. **[事实] RL 后训练有净收益，但收益和流失同时发生。**
   - 总到达：BC 116，u128 160，C 182，T 172（共 420）。
   - C 与 T 是从同一个 u128 续训出来的两条臂，C 不加保持项，T 加了保持项。两者之间是保持与新增的权衡：T 保住更多已有成功，C 新增更多成功。
2. **[事实] 净收益主要集中在目标高度 ≥3m 的任务。**
   - 目标 <3m：BC 103，C 107，T 111（共 215）。
   - 目标 ≥3m：BC 13，C 75，T 61（共 205）。
   - 低高度组的净值接近 0，但组内有大量替换。以 C 为例：保住 BC 的成功 81，丢掉 22，新增 26。
3. **[复算] 高目标组的新增收益，主要不是"学会爬升"。**
   - C 在高目标组新增的 66 个成功条件，起点中位高度 3.69m，目标中位高度 3.48m，本来就不需要爬升。
   - BC 在这些条件下失败时，离目标最近的水平距离中位数是 2.30m；C 是 0.45m。
   - 所以更准确的说法是"在示范高度带之外的导航有改善"。为什么会改善，目前没有裁决。
4. **[事实] 绕障有改善，但规模小。**
   - 目标 <3m 且受阻（按既有判据，共 95 个条件）：BC 16，u128 19，C 25，T 21。
   - 其中密集受阻（共 75 个条件）：BC 6，u128 9，C 15，T 11。
5. **[事实] "越训越差"不是必然规律。**
   - A1 从 u128 不中断续训到 u256，结果 129。C 从同一 checkpoint 恢复后续训，结果 182。
   - 两条路径在第一次更新时 policy_loss 就已经不完全相同，差异来源尚未定位。
   - 这说明结果对很小的差异都非常敏感。凡是只跑一次的比较，都必须带上运行噪声基准。
6. **[假设] 有两个可以改进的方向：**
   - (a) 有效动作通道得到的更新约束不足；
   - (b) z 方向的采样尺度和截断，与"停在目标下方"这类失败有关。
   - 这两条用来指导工程实验，不当作已证明的根因。

## 1. 项目目的与判定口径

**目标：** 以 E5 扩散策略 BC 为起点，通过 RL 后训练，明显提高安全到达率，并至少在下面三项能力中改善一项：
- 提前避障；
- 扩大 x/y/z 空间支持；
- 密集障碍中的绕行、脱困与恢复。

**主终点：** 实际执行的 H4 连续路径，在碰撞之前首次进入半径 0.5m 的目标球。

**统计口径：**
- dev 420 = 84 个任务 × 5 次重复。同一任务的 5 次重复，结局几乎完全一致，所以有效样本数更接近 84。
- 单次训练运行之间的差异可以超过 50 个条件。任何单 seed 的结论都要附上匹配对照，并按世界聚类报告区间。

### 2.4 失败形态

- **停在目标下方：** 进入目标 1m 内后超时，且离目标最近时比目标低 0.3m 以上。BC 33 次，u128 73 次，C 19 次，T 63 次。这类情况下，水平方向已经对准，停滞期间 Δz 的中位数接近 0。
- **窄余量任务碰撞：** 例如 front_offset cfg03。BC 通过时离障碍最小 0.27m，之后逐步减小，到 A1 u256 和 C 时都是 5/5 碰撞，T 仍是 5/5 到达。
- **已排除的解释：**
  - 冲过头：进入目标附近时的速度，与成功回合相同；
  - 普遍贴近障碍：在没有碰撞的回合里，RL 的最小间隙反而大于 BC。

### 2.5 训练过程（B2560，训练模式）

- 训练模式的到达率：前 32 轮 24.7%，97–160 轮约 39.6%，最后 32 轮 28.4%，与评价的走势一致。
- EV 均值 0.53，退化阶段没有下降。
- dense_recovery 在 22–34% 之间波动。

## 3. 机制分析（工作假设）

### 3.1 惰性通道参与代理目标

- **[事实]** 11 维动作中，有 7 维（下标 3–8、10）在轻量环境中不参与位置积分，也不进入观测。PPO 的概率比是 H8×11 共 88 个元素 logprob 的均值。PX4 部署时会用到这 7 维。
- **[事实]** 在扩散去噪的中间步，这些通道的中间值会被下一次 U-Net 读取，可能影响位置通道的生成。只有**最后一个去噪步**上它们的采样噪声，对环境才确实没有后果。这一现象在 10-22 的审查中已经讨论过。
- **[事实，Q2]** u128→u256 期间，惰性通道 v_y、a_y 的变化（0.17σ、0.18σ）大于有效通道（0.05–0.11σ）。通道之间相关，这只能说明这些通道在动，不能说明它们造成了能力退化。
- **[撤回]** "纯噪声梯度""64% 的噪声"。64% 只是元素个数的占比，不是梯度贡献的占比。
- **[假设]** 最后一步惰性元素的梯度可能加重无方向的漂移。检验办法：在同一个冻结父状态上，比较掩码开和关两种情况下的梯度（指引中的 C1），再做 X/K 工程对照。

### 3.2 代理 KL 与行为变化

- **[事实]** B2560 的 clip_fraction 约 0.08%，approx_kl 约 1e-5，KL 门禁从未触发。B1280 和 B2560 只改了提交组织，结果是 0/420 对 160/420。
- **[撤回]** "信任域失效"，以及由端点差除以轮数得出的 5mm 阈值。PPO 的 clip 是对目标函数的裁剪，不是物理位移的上限。约束弱只能放大有害更新，解释不了有害方向从哪里来。
- **[假设]** 当前的代理指标，不足以反映固定输入下动作的实际变化。处理办法是逐轮监测动作漂移（指引 T2），先只记录，不设门禁。

### 3.3 处于边界的能力与近确定性评价

- **[事实]** 窄余量任务的间隙随训练逐步减小，直到碰撞。5 次重复的结局几乎一致。T 的保持项实际强度只有 PPO 梯度的约 0.047 倍，却保住了 BC 原本 5/5 成功任务中的 100/105，而 C 是 85/105。
- **[假设]** 很小的行为变化就可能让一个任务整体翻转。保持类干预对这一类流失有效，这是目前唯一有干预证据支持的机制。

### 3.4 采样尺度

- **[事实，代码]** 采样和 logprob 的噪声下限都是标量 0.1，作用在逐维标准化的空间里，归一化尺度是 1/σ_demo（x 为 4.27，z 为 27.2）。
- **[事实，Q2]** 同一状态下随机采样，H4 的标准差为 x 4.7cm、y 4.8cm、z 0.8cm，三个策略几乎相同。
- **[撤回]** "所以绕障路线采不到"。单个 H4 的局部散布不等于闭环下整条路线的探索范围，而且绕障确实有小幅改善。
- **[假设]** z 方向的采样尺度偏小，可能与"停在目标下方"有关。这需要闭环续飞来检验（指引 C2），并且只针对这一种失败。

### 3.5 x0 截断

- **[事实，代码]** BC 配置为 `clip_sample: True`，范围取默认值 1.0。动作是逐维高斯标准化的，所以 ±1 对应示范分布的 ±1σ。DPPO 有意继承这个设置。
- **[事实，代码]** vendor 实现先用**未截断**的 x0 推出 ε，再截断 x0。DDIM 均值里含 ε 项，所以越界元素在中间去噪步仍有梯度路径。只在最后几步，因为 ᾱ_prev→1、方向系数→0，这条路径才基本消失。
- **[事实，代码]** 训练采样在均值之后还会再加噪，`final_action_clip_value=None`。所以 ±1σ 只是确定性评价的硬上限，不是随机训练中动作的上限。
- **[撤回]** "梯度死区导致漂移不可逆""训练动作被截断在 ±1σ"。
- **[假设]** 截断限制了确定性评价能输出的动作，对学习可能有影响。修改截断就是一种新的采样协议，必须和原协议分开报告。

### 3.6 示范覆盖

- **[事实]** 示范高度几乎都在 3m 以下，而训练和评价中有一半目标在 3m 以上。
- **[假设]** BC 在示范高度带之外的导航能力弱，RL 在这里的改善空间最大。至于改善是靠什么实现的（例如对状态中位置 z 超出分布的处理方式），尚未裁决。

### 3.7 reward、critic、编码器、采样模式

- **reward：** 向目标爬升能直接得到 newbest，但这并不保证在当前生成分布下局部梯度足够可靠。窄余量任务上，risk 二次项的惩罚偏弱。不改也不排除，放在后续做单因素实验。
- **critic：** EV 正常，不能排除条件性偏差。
- **训练与评价采样模式不一致：** 两边的到达率曲线走势一致，削弱了"只是评价模式问题"这一解释，但不能排除两者之间存在交互。
- **编码器、H8 尾段：** 未裁决，暂不改动。

## 4. 改进计划（工程实验）

**原则：** 只要有合理依据、风险可控、结果可比较，就可以实验，不需要先证明根因。组合实验如果有效，就先保留，之后再做消融。

1. **独立验证现有候选（优先，不等待 X）：**
   - 冻结 BC、u128、C、T，按原协议在 test12 上验证，预算为 4×48×R 回合，R 在运行前定死。
   - 本次揭示结果之后，X 以后在 test12 上的比较只算描述性结果，不具备独立验证的身份。
   - 单独出执行指导。
2. **开发线 X/K：** 从 u128 分叉，两臂同 seed、同预算。
   - **K**：现有配置，作为匹配对照，同时也是 C 的一次重复；
   - **X**：有效通道掩码，加上 C2 通过后的采样修改，可选再加自模仿保持（T5，需用户确认）。
   - 两臂都开启漂移监测，判定以固定的 u256 端点为准。具体见任务指引 v1.1。
3. **之后（10-31 以后）：**
   - 对有效的组合做消融；
   - reward 单因素实验：放宽 risk 预警距离，或用严格 PBRS；
   - 结构化探索；
   - PX4 部署验证，重点核查速度、加速度、yaw-rate 这几维的执行语义；
   - 合成几何 bug 单独作为协议变更处理。

## 5. 预期与局限

- **能直接对准的问题：** 已有成功的流失（掩码、监测、可选的自模仿）；停在目标下方（采样修改，前提是 C2 通过）。
- **覆盖不到的问题：** 高目标区间的水平导航（这是当前收益的主要来源）、密集绕障、运行之间的波动。
- **检出能力：** 只有一对 X/K，只能检出很大的效果。与 K 相比差距在几十个条件以内的，都不能单独据此判定。
- **不做成功数预测。** 交付的是可信的裁决，不预设结果一定是正向的。

## 附录：复算口径

- **受阻：** `segment_obstacle_collision(start, goal, obstacles, 0.1)`，与既有独立复算一致。
- **停在目标下方：** 超时，路径上离目标最近的点距离 <1m，且该点比目标低 0.3m 以上。
- **高目标新增的来源：** 取 C 成功而 BC 失败的条件，统计起点和目标高度，以及 BC 和 C 在离目标最近时的水平距离、高度差。
- 脚本 `an.py`、`an2.py`、`a2.py` 待放入仓库，供独立复核。
